# Nex для Android (полная сборка этапов 1–7)

ИИ-агент Nex / Некси для Android на собственных API-ключах пользователя (Gemini, OpenAI, Claude, DeepSeek, NVIDIA).

## Что реализовано
- **Онбординг (4 шага):** приветствие с анимированным 3D-шаром, выбор языка (RU/EN), запрос разрешений, выбор голоса (Некс / Некси), ввод ключей API.
- **Интерфейс в стиле Claude:** шторка с историей чатов, проекты с рабочей папкой (SAF), библиотека артефактов, настройки (6 вкладок: ИИ, Голос, Память, Доступ, Защита, Язык), аккаунт.
- **Модели и маршрутизация:** 4 авто-профиля (`Nex Atom`, `Nex Quark`, `Nex Sel`, `Nex Foton`), параметр «Усилие», сворачиваемые списки провайдеров, обновление каталогов моделей по API.
- **Агент и безопасность:** реальный tool-calling (календарь, контакты, SMS, звонки, напоминания/будильники, маршруты, поиск в сети, файлы папки проекта, память) и жёсткий неотключаемый перехватчик подтверждения покупок (`SafetyGuard`).
- **Мессенджеры и экран:** `NotificationListenerService` (чтение и прямые ответы в Telegram/WhatsApp) и `AccessibilityService` (запуск приложений, чтение экрана, ввод и нажатия с проверкой покупок).
- **Голос и ассистент по умолчанию:** `SpeechRecognizer` + `TextToSpeech` (мужской/женский голос, скорость) и `VoiceInteractionService` + всплывающий оверлей `AssistActivity`.
- **Почта:** встроенный TLS-клиент IMAP4rev1 + SMTP (SSL 465 / STARTTLS 587) и поддержка Gmail REST API v1 по OAuth2 Bearer-токену.
- **Артефакты и медиа:** просмотрщик презентаций, редактируемые таблицы с автосуммой, Markdown-документы, изолированный HTML WebView, а также реальная генерация картинок (Gemini, OpenAI) и видео (Gemini).

## Сборка через GitHub Actions
1. Создай новый репозиторий на GitHub (можно приватный).
2. Загрузи в корень репозитория ВСЕ файлы из этого архива (включая `.github/`, `app/`, `gradle/`, `gradlew`, `gradlew.bat`, `*.kts`).
3. Открой вкладку **Actions** и дождись выполнения workflow **Build APK**.
4. В разделе **Artifacts** скачай `nex-debug-apk`, распакуй и установи `app-debug.apk` на телефон.

## Важно для Android 13+ (ограниченные настройки)
При установке APK не из Google Play система Android по умолчанию блокирует тумблеры **Уведомления мессенджеров** и **Спец. возможности**. Чтобы включить их:
1. Открой **Настройки телефона → Приложения → Nex**.
2. Нажми меню `⋮` в правом верхнем углу → **Разрешить ограниченные настройки**.
3. Вернись в **Настройки Nex → Доступ** и включи нужные службы.
