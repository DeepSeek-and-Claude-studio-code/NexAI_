# Nex — полная экосистема (Android + Windows / Linux + Nex Code)

Единый репозиторий со всеми приложениями проекта **Nex / Некси**:

## Модели Nex
- **Nex Atom** — быстрые ответы и простые задачи
- **Nex Quark** — золотая середина (базовая)
- **Nex Sel** — самая сильная для сложных задач
- **Nex Foton** — генерация и ИИ-редактирование картинок, фото и видео

## Основные возможности (Android + Windows / Linux)
1. **Начальный экран и первоначальная настройка:** экран приветствия с анимированным 3D-шаром и слоганом **«Знакомьтесь Некс ваш помощник»**, далее пошаговая настройка: Вход в аккаунт (Почта или Google) → Разрешения → Выбор голоса (Некс / Некси) → API-ключи.
2. **Аккаунты (Почта и Google) и полное сохранение:**
   - Изолированное хранилище на аккаунт (PBKDF2-HMAC-SHA256 для почты, OAuth 2.0 + PKCE для Google).
   - Сохраняются и синхронизируются: **API-ключи** (шифрование Keystore / DPAPI / Keyring + AES-256-GCM), **чаты**, **картинки и видео**, **артефакты**, **настройки** и **последняя выбранная модель**.
   - Облачная синхронизация в **Google Drive (`appDataFolder`)** для Google-аккаунта и кросс-платформенный зашифрованный экспорт/импорт **`.nexvault`** (совместим между Android, Windows и Linux).
3. **Реальные артефакты:** создание вручную и через ИИ, просмотр, живое редактирование текста/кода/слайдов/таблиц (добавление строк и колонок + автосумма), песочница HTML, удаление и экспорт в реальный файл (`.md`, `.csv`, `.json`, `.html`).
4. **Реальное редактирование фото и видео (Фото и видео студия):**
   - **Фото (офлайн + ИИ):** яркость, контраст, насыщенность, фильтры (Ч/Б, Сепия, Тёплый, Холодный), поворот, отражение, обрезка (1:1, 16:9, 4:5), текст поверх фото, плюс ИИ-редактирование фото (Gemini / OpenAI) и оживление фото в видео (Gemini).
   - **Видео:** на Android — нативная обрезка по времени без перекодирования и удаление звука (`MediaExtractor` + `MediaMuxer`) + извлечение кадра в фото (`MediaMetadataRetriever`); на Windows/Linux — обрезка, скорость (0.5x–2x), фильтры, титры, отключение звука, извлечение кадра и экспорт в `.webm`.
5. **Сборка через GitHub Actions:** `.github/workflows/build-android.yml` (APK), `build-desktop.yml` (Windows `.exe` + Linux `.AppImage`/`.deb`), `verify-nex-code.yml`.

## Хранение всех файлов на Google Диске пользователя
- При подключении Google-аккаунта (или привязке Google Диска к почтовому аккаунту) Nex автоматически сохраняет **все файлы** на личный Google Диск пользователя (бесплатно в рамках квоты 15 ГБ+):
  - `Nex/Vault/nex_state_vault.nexvault` — зашифрованные AES-256-GCM ключи API, чаты, память, настройки и последняя выбранная модель.
  - `Nex/Media/` — все сгенерированные, загруженные и отредактированные фото и видео любого размера (загрузка чанками по 4 МБ через Resumable Upload API).
  - `Nex/Artifacts/` — все артефакты как обычные читаемые файлы (`.md`, `.csv`, `.html`, `.json`).
  - `Nex/Attachments/` — все файлы и фото, прикреплённые в чатах.
- По умолчанию используется видимая папка `Nex/` на Google Диске (`drive.file`), в настройках аккаунта можно переключить на скрытую `appDataFolder` (`drive.appdata`).
